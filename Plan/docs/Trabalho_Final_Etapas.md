## TRABALHO FINAL

Desenvolver um sistema web completo que atenda a uma necessidade ou problema
real, como uma aplicação de gerenciamento de tarefas, um sistema de cadastro de usuários, ou um portal de eventos.

O sistema deve ser desenvolvido utilizando tecnologias como:

- Front-end: HTML, JavaScript, Bootstrap e React.
- Back-end: Node.js, Express, ou outra tecnologia compatível.
- Banco de Dados: MySQL, MongoDB, ou qualquer banco de dados relacional ou não-relacional que o grupo escolher.

Cada etapa contará com uma apresentação formal, onde a equipe demonstrará o
progresso e as funcionalidades desenvolvidas.

**Entrega 1: Plano de Trabalho.**
**Entrega 2: MVP (Mínimo Produto Viável).**
**Entrega 3: Apresentação Final (Com relatório)**

# Etapa 1 (Plano de Trabalho): Projeto Inicial

Objetivos da Etapa:

## 1. Planejamento do Projeto:

- Definir o escopo do sistema: funcionalidade principal, público-alvo e
  tecnologias utilizadas.
- Diagramas de Caso de Uso (Principais Fluxos)
- Requisitos Funcionais e Não Funcionais.
- Criar wireframes ou protótipos das telas principais da aplicação.
- Estruturar o banco de dados: criar diagramas de ER
  (Entidade-Relacionamento) ou modelos de dados.
- Definição de cronograma de execução das atividades.

## 2. Apresentação:

Cada equipe deve apresentar seu planejamento juntamente com a
divisão de equipe escolhida para o desenvolvimento inicial,
funcionalidades básicas e uma breve explicação da arquitetura
adotada.

Divisão de Funções na Equipe (Sugerida):

- Desenvolvedor Front-end: Responsável por implementar a interface visual
  do sistema (HTML, CSS, Bootstrap e React).
- Desenvolvedor Back-end: Cuida da configuração do servidor e da
  integração com o banco de dados.
- Designer UX/UI: Desenvolve o layout, wireframes, e a experiência do
  usuário.
- Gerente de Projeto: Coordena o time, organiza o cronograma, e realiza a
  integração entre front-end e back-end.

# Etapa 2: MVP (Mínimo Produto viável)

## 1. Implementação Front-end Inicial:

- Desenvolver a interface básica do usuário (UI) utilizando as
  tecnologias escolhidas.
- Utilizar um framework front-end (como Bootstrap ou React) para
  implementar responsividade.

## 2. Back-end Inicial:

- Implementar o back-end inicial para suportar as principais operações
  CRUD (Create, Read, Update, Delete).
- Integrar o banco de dados e permitir interações básicas com ele
  (exemplo: cadastrar usuários, criar registros, etc.).

- Relatório do Sistema:
  - Descrição das funcionalidades do sistemas desenvolvidas até o
    momento.
  - Tecnologias utilizadas.
  - Apresentação de diagramas e decisões técnicas adotadas.

## 4. Apresentação:

- Cada equipe deve apresentar as funcionalidades desenvolvidas até o
  momento, incluindo o design inicial, funcionalidades básicas e uma
  breve explicação da arquitetura adotada.

Divisão de Funções na Equipe (Sugerida):

- Desenvolvedor Front-end: Responsável por implementar a interface visual
  do sistema (HTML, CSS, Bootstrap ou React).
- Desenvolvedor Back-end: Cuida da configuração do servidor e da
  integração com o banco de dados.
- Designer UX/UI: Desenvolve o layout, wireframes, e a experiência do
  usuário.
- Gerente de Projeto: Coordena o time, organiza o cronograma, e realiza a
  integração entre front-end e back-end.

## Critérios de Avaliação (Etapa 2):

- Planejamento do Projeto (20%) – Acompanhamento das sprints, Qualidade
  do escopo, wireframes e planejamento de banco de dados.
- Interface de Usuário (UI) (30%) – Implementação correta de HTML, CSS e
  responsividade.
- Funcionalidades Iniciais (30%) – Operações CRUD e integração com
  banco de dados funcionando.
- Apresentação e Relatório do Sistema (20%) – Clareza na apresentação,
  divisão de trabalho entre os membros e justificativa das escolhas
  tecnológicas.

# Etapa 3: Desenvolvimento Completo e Finalização do Sistema

Objetivos da Etapa:

## 1. Desenvolvimento Avançado:

- Implementar funcionalidades avançadas, como autenticação de
  usuários (login e registro), pesquisa, e filtragem de dados.
- Melhorar a interface do usuário, tornando-a mais interativa e funcional,
  utilizando JavaScript e frameworks como React (caso escolhido).

## 2. Integração Completa:

- Realizar a integração final entre o front-end e o back-end, garantindo
  que o sistema funcione como um todo.
- Utilizar um serviço de hospedagem (como Heroku ou Vercel) para
  disponibilizar o sistema online.

## 3. Apresentação Final + Relatório Completo:

- Apresentação detalhada do sistema final, com foco nas
  funcionalidades implementadas, desafios enfrentados e superados, e
  nas melhorias realizadas desde a primeira etapa.
  Divisão de Funções na Equipe (Sugerida):
  - Desenvolvedor Front-end: Finalizar e polir a interface do usuário,
    implementando funcionalidades mais complexas (como animações,
    interações dinâmicas com JS/React).
  - Desenvolvedor Back-end: Implementar autenticação, autorização e
    operações avançadas no back-end.
  - Gerente de Projeto: Coordenar o trabalho e garantir a entrega final, escrita
    do relatório final com todos os detalhes técnicos.

## Critérios de Avaliação (Etapa 3):

- Funcionalidades Avançadas + Relatório Final (40%) – Implementação de
  autenticação, pesquisa, e outras operações avançadas.
- Qualidade da Integração Front-end/Back-end (30%) – O sistema deve
  funcionar de forma integrada e eficiente.
- Design e Usabilidade (20%) – Interface do usuário aprimorada e usabilidade
  testada e validada.
- Apresentação Final (10%) – Clareza, divisão de trabalho e solução dos
  desafios enfrentados.
